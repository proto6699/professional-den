# professional-den

Professional portfolio of Faris Albeyahi (proto6699): UAV/UAS, Rust software, telemetry, Linux and embedded projects, with build notes and measured results.

Live: https://proto6699.github.io/professional-den/

This is the light-only, work-facing twin of [the Den](https://github.com/proto6699/echo). Same projects, same layout and working features (project map, project details, build notes, mobile menu), without the CRT mode, soundtrack or oracle.

Single static page: `index.html` plus images. No build step; served by GitHub Pages from `main`.
